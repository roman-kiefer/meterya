# Accessibility

## Scope and current status

This repository provides installation instructions and deployment examples. Accessibility of the web interface is maintained in [Meterya App](https://github.com/roman-kiefer/meterya-app). Documentation should use clear headings, descriptive links, and text explanations for essential visual information.

There is no documented comprehensive accessibility audit or verified WCAG conformance assessment for this repository. Known barriers are tracked through issues; the absence of an issue is not evidence that a flow is accessible.

## Report a barrier

For installation documentation barriers, open a bug report here. For keyboard navigation, screen reader, contrast, or other web interface barriers, report the issue in [Meterya App](https://github.com/roman-kiefer/meterya-app/issues/new/choose).

Use the [bug report form](https://github.com/roman-kiefer/meterya/issues/new?template=bug_report.yml). If the form itself prevents reporting, open a [blank issue](https://github.com/roman-kiefer/meterya/issues/new). No personal medical information is needed. Remove private data from attachments.

## Contributing improvements

Include accessibility considerations when changing controls, navigation, error feedback, or documentation. Describe the affected task and the keyboard or assistive-technology checks actually performed. See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution process.
